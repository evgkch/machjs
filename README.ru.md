# fsmjs tokens

Общий словарь оформления инструментов fsmjs: палитра, типографика, шаги отступов, радиусы и
полосы состояний — custom properties в одном файле `tokens.css`.

Подключается git-сабмодулем и импортируется страницей или виджетом:

```css
@import "./tokens/tokens.css";
```

Используется в [fsmjs-inspector](https://github.com/evgkch/fsmjs-inspector) и
[fsmjs-examples](https://github.com/evgkch/fsmjs-examples).
