# machjs tokens

Общий словарь оформления инструментов machjs: палитра, типографика, шаги отступов, радиусы,
полосы состояний — и собранные из них элементы управления. Один файл, `tokens.css`.

Страницы и виджеты самого инспектора импортируют его отсюда, относительным путём. Пакет
публикует копию, поэтому на странице со своими виджетами палитру подключают по имени:

```css
@import "@evgkch/machjs-inspector/tokens.css";
```

Виджетам он обязателен: палитра наследуется в теневое дерево как custom properties, и без
токенов виджет остаётся без цветов.

## Два слоя

Порядок слоёв задан в самом файле, первой строкой после шапки: `@layer tokens, controls;`.
На странице со своим слоем пишем `@layer tokens, page;` и получаем порядок `tokens, controls, page`.

| Слой       | Что внутри                                                                     |
| ---------- | ------------------------------------------------------------------------------ |
| `tokens`   | Custom properties, `* { box-sizing }`, `.tag`/`.label`, форма угла               |
| `controls` | `button`, `input`, `select`, `textarea`, `kbd`: одна высота, одно кольцо фокуса |

Каждый селектор слоя `controls` обёрнут в `:where()` и потому не имеет специфичности: страница
перекрывает любое правило обычным `button { … }`.

## Размеры элементов управления

| Свойство       | Значение | Где применяется                                     |
| -------------- | -------- | --------------------------------------------------- |
| `--control`    | 36px     | Каждый нажимаемый элемент и каждое поле ввода       |
| `--control-sm` | 30px     | Плотная полоса внутри другого элемента — `.dense`   |
| `--ui`         | 14px     | Текст внутри элемента управления                    |
| `--ui-sm`      | 13px     | Текст меньшего размера рядом                        |

36px — это полтора модуля (`--cell` равен 24px).
